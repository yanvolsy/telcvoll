# Email Branding Fix

Applied only to `telcvoll_fixed_admin_css.zip`.

## Unified email branding
- Verification email
- Password reset email
- Subscription activation email
- Admin notification email
- Admin campaign email

All outgoing emails now use the same shared template with:
- TELC Voll logo (`/assets/TELC_Voll_AppIcon_Light.png`)
- TELC Voll name
- Arabic platform tagline: `منصة التحضير لامتحانات اللغة الألمانية · B1 · B2 · C1`
- Same dark header
- Same TELC Voll orange accent/border
- Same white content card and rounded frame
- Same footer and site link
- Same `EMAIL_FROM` sender (`TELC Voll <noreply@telcvoll.de>` by default)

The existing email-specific content and actions remain different; only the common branding/frame was standardized.
